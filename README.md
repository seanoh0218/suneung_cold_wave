# 수능 한파는 사라지고 있는가?
### CO₂ 증가(신호)와 엘니뇨(잡음)로 본 수능 시기 서울 기온 분석

---

## 1. 주제

- **연구 질문**: 수능 시기 서울의 추위는 CO₂ 증가로 약해졌는가? 그런데도 어떤 해에는 왜 여전히 추운가? 엘니뇨·라니냐(ENSO)가 그 차이를 설명하는가?
- **가설**: CO₂ 농도(장기 온난화 신호)는 수능 시기 기온과 양의 상관을 보이지만, ONI(해마다의 자연 변동)와의 상관은 약할 것이다.
- **통합과학 연결**: 지구 열수지와 온실효과, 엘니뇨–남방진동(ENSO)
- **독서 활동 연계**: 『기후의 과학』(마나베 슈쿠로)에서 정리한 신호 대 잡음 개념을 공공데이터 분석에 적용

---

## 2. 변수와 자료

**분석 기간**: 2000~2025년 (26년)

| 변수 | 내용 | 출처 |
|---|---|---|
| **Y** | 매년 11월 8~21일 서울 평균 최저기온 | 기상청 기상자료개방포털, 종관기상관측(ASOS) 일자료, 서울(108) |
| **X1** | 안면도 CO₂ 배경대기농도 연평균 | 기상청 기상자료개방포털, 기후변화감시 → 온실가스 |
| **X2** | ONI의 ASO 값 (8~10월 평균) | NOAA CPC Oceanic Niño Index |
| 보조 | 실제 수능일 서울 최저기온 | ASOS 일자료 + 수능 시행일(한국교육과정평가원) |

- X1 = 장기 온난화 **신호**
- X2 = 해마다의 자연 변동 **잡음**

---

## 3. 이렇게 정한 이유

| 선택 | 이유 |
|---|---|
| 11월 8~21일 | 2007학년도 이후 수능은 대부분 11월 둘째~셋째 주 목요일에 시행됨. 단, 2001~2003년(11월 5~7일), 2005·2017년(11월 23일), 2020년(12월 3일)은 이 기간 밖이라 실제 수능일 기온은 따로 비교함 |
| 최저기온 | 수험생이 체감하는 추위는 아침 등교 시간 기온 |
| 14일 평균 | CO₂·엘니뇨는 하루 날씨가 아니라 그 시기의 기후를 바꿈. 하루 기온은 잡음이 너무 큼 |
| 안면도 | 오염원 영향을 받지 않은 배경대기농도. CO₂는 대기 중에 고르게 섞임 |
| CO₂ 연평균 | 광합성에 의한 계절 변동을 없애고 누적된 온실효과를 반영 |
| ONI 사용 | 기상청 엘니뇨 정의와 같은 방식(Niño 3.4 해역, 3개월 이동평균) |
| ASO | ASO는 수능 시기 전에 확정되는 값. SON(9~11월)은 분석 기간인 11월 자료를 포함해 데이터 누수가 생김. |
| 엘니뇨 기준 ±0.5 | 기상청·NOAA의 엘니뇨·라니냐 판단 기준 |
| 0℃ 미만 일수 비율 제외 | 평균 최저기온과 상관이 매우 높아(r = −0.83) 같은 정보이므로 평균 최저기온만 사용 |
| 시간 순서로 검증 | 무작위로 나누면 미래 연도로 과거를 맞히는 데이터 누수가 생김. 2000~2019년 학습, 2020~2025년 검증 |

---

## 4. 분석 순서

1. **Y 만들기**: 일자료에서 11월 8~21일만 골라 연도별 평균 최저기온 계산 (연도마다 14일이 다 있는지 확인)
2. **대표성 확인**: 실제 수능일 최저기온과 Y의 상관계수
3. **추세 보기**: Y와 CO₂의 연도별 그래프 + 추세선
4. **ENSO 비교**: ONI와 Y의 산점도, 라니냐·평상시·엘니뇨 해별 상자그림
5. **회귀분석**: `Y = a·CO₂ + b·ONI + 상수` (2000~2025년 전체)
6. **검증**: 2000~2019년으로 학습 → 2020~2025년 예측 → 실제값, 학습 기간 평균값과 비교

## 5. 결과 요약

| 분석 | 결과 | 그림 |
|---|---|---|
| 수능일 대표성 | 실제 수능일 최저기온과 Y의 r = 0.44 | `scatter_suneung.svg` |
| Y 추세 | 10년에 약 +0.82℃, 해마다 변동이 큼 | `temp_yr_trend.svg` |
| CO₂ 추세 | 10년에 약 +24.2ppm, 추세선에 거의 붙어 있음 | `co2_trend.svg` |
| ONI와 Y | r = −0.04, 관계 거의 없음 | `scatter_oni.svg` |
| ENSO 해별 비교 | 평균 라니냐 5.06℃(6년), 평상시 3.01℃(13년), 엘니뇨 3.67℃(7년). 그룹 간 차이보다 그룹 안 흩어짐(표준편차 2~3℃)이 큼 | `box_enso.svg` |
| 회귀 (2000~2025) | a = 0.033℃/ppm, b = −0.086℃, R² = 0.067 | |
| 검증 (2020~2025) | R² = −1.22, RMSE = 3.6℃ (평균값만 쓴 경우 3.0℃) | `validation.svg` |

**해석**
- CO₂ 증가와 같은 방향의 완만한 온난화 신호는 보이지만, 해마다의 잡음이 훨씬 커서 CO₂와 ONI로는 수능 시기 기온 변동의 약 7%만 설명됨
- 검증에서 모델이 평균값을 찍는 것보다 못함 → 두 변수만으로는 특정 해의 수능 추위를 예측할 수 없음
- 2015년(강한 엘니뇨, 8.97℃로 가장 따뜻함)과 2023년(강한 엘니뇨, 0.44℃로 매우 추움)처럼 같은 엘니뇨 해도 결과가 정반대
- 2000~2019년만으로 학습하면 b(ONI) = 0.97이지만 2025년까지 넣으면 −0.09로 부호가 바뀜 → 표본이 작아 계수가 불안정함

## 6. 한계

- 26년이라 장기 추세를 판단하기엔 짧고, ENSO 그룹별 표본도 6~13년뿐임
- 서울 한 지점이라 도시 열섬 효과가 섞여 있을 수 있음
- 북극진동(AO), 시베리아 고기압 등 겨울철 한파의 주요 요인은 넣지 않음
- 엘니뇨·라니냐를 ASO 한 값으로만 나눔 (공식 판정은 여러 달 지속 여부를 봄)
- 상관관계 ≠ 인과관계

## 7. 후속 탐구

- 2026년(강한 엘니뇨 해) 수능 시기 기온을 예측하고 실제값과 비교
- 북극진동 지수, 북극 해빙 면적, 연안 수온 등 변수를 추가해 설명력 비교
- 1973년부터의 장기 자료로 기간을 늘려 추세 재확인

## 8. 실행 방법

```bash
pip install numpy pandas matplotlib koreanize-matplotlib seaborn scikit-learn
python main.py
```

- `data/` 폴더의 csv가 없으면 `raw_data/`에서 자동으로 다시 만듦
- 그림은 `figures/`에 저장되고, 회귀·검증 결과는 터미널에 출력됨

**파일 구성**

| 파일 | 역할 |
|---|---|
| `preprocess.py` | 원자료 정리, 11월 8~21일 추출, 실제 수능일 기온 추출(`SUNEUNG_DATES`) |
| `analysis.py` | 추세·산점도·상자그림 그리기 |
| `main.py` | 전체 실행, 회귀분석, 검증 |
| `raw_data/` | 내려받은 원자료(csv) |
| `data/` | 전처리된 자료 |
| `figures/` | 결과 그림 |
