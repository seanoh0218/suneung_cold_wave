# 수능 한파는 정말 사라졌을까?
### 온실효과(신호)와 엘니뇨(잡음)로 본 수능 시기 기온 변화 — 탐구 설계

---

## 1. 주제

- **연구 질문**: 수능 시기 서울의 추위는 CO₂ 증가로 약해졌는가? 그런데도 어떤 해에는 왜 여전히 추운가? 엘니뇨·라니냐가 그 차이를 설명하는가?
- **통합과학 연결**: 지구 열수지와 온실효과, 엘니뇨·라니냐
- **독서 활동 연계**: 『기후의 과학』(마나베 슈쿠로) 탐구에서 정리한 지문(fingerprint)과 신호 대 잡음 개념을 내 데이터에 적용

---

## 2. 변수

**분석 기간**: 본 분석 2000~2025년 (26년) / 선택: 장기 분석 1973~2025년

| 변수 | 내용 | 출처 |
|---|---|---|
| **Y1** | 매년 11월 8~21일 서울 평균 최저기온 | 기상자료개방포털 → 종관기상관측(ASOS) 일자료, 서울(108) |
| **Y2** | 같은 기간 중 최저기온 0℃ 미만인 날의 비율 | 같음 (기상청 극한기후지수 '서리일' 정의) |
| **X1** | 안면도 CO₂ 배경대기농도 연평균 | 기상자료개방포털 → 기후변화감시 → 온실가스 ✅ |
| **X2** | ONI의 SON 값 (9~11월 평균) | NOAA CPC ONI 표 (기상청 엘니뇨 정의와 같은 방식) |
| X3 (선택) | 서해·동해 연안 10월 평균 수온 | 국립수산과학원 한국해양자료센터(KODC) 연안정지관측 |
| X4 (선택) | 9월 북극 해빙 면적 | 기상청 기후감시 → 북극해빙 (원자료 NSIDC) |

**역할**
- X1 = 장기 온난화 **신호**
- X2 = 해마다의 자연 변동 **잡음**

---

## 3. 분석 순서

1. **Y 만들기**: 일자료에서 11월 8~21일만 골라 연도별 평균(Y1)과 0℃ 미만 비율(Y2) 계산
2. **대표성 확인**: 1993년 이후 실제 수능날 최저기온과 Y1의 상관계수 구하기
   - 1993년은 11월 16일 시험만 사용 (8월 1차 제외)
   - 2020년(2021학년도)은 12월 3일 시행이라 따로 표시
3. **추세 보기**: Y1, X1을 연도별 그래프로 그리고 추세선 넣기
4. **엘니뇨 비교**: 엘니뇨 해 / 라니냐 해 / 중립 해로 나눠 Y1 평균 비교 (기준 ±0.5℃)
5. **회귀모델**: `Y1 = a·X1 + b·X2 + 상수`
   - a → 신호의 크기, b → 잡음의 크기
6. **검증**: 2000~2019년으로 모델을 만들고 2020~2025년을 예측해서 실제 값과 비교
7. **(선택) 확장**
   - X3, X4를 하나씩 추가해서 모델이 더 잘 맞는지 비교
   - X1 대신 '연도'를 써서 1973~2025년 장기 분석 (먼저 2000~2025년 CO₂와 연도의 상관계수가 거의 1인지 확인)
8. **올해 예측**: 2026년 CO₂ 추정값과 최근 ONI(ASO, 8~10월)를 넣어 올해 수능 시기 기온을 예측하고 실제와 비교
   - 2026년은 강한 엘니뇨 해 → "강한 엘니뇨인 올해 수능은 추울까?"

**추가 그래프 (선택)**: 안면도 CO₂ 월 자료로 그래프 → 계절 변동(광합성, 탄소 순환) + 장기 증가(인간 활동)를 한 그림에서 보여주기

## 4. 보고서에 쓸 "왜 이렇게 했나" 근거

| 선택 | 이유 |
|---|---|
| 11월 8~21일 | 수능은 11월 둘째~셋째 주 목요일에 시행 → 수능일이 될 수 있는 날짜 전체 |
| 최저기온 | 수험생이 체감하는 추위는 아침 등교 시간 기온 |
| 14일 평균 | CO₂·엘니뇨는 하루 날씨가 아니라 그 시기의 '기후'를 바꿈 |
| 0℃ 미만 | 기상청 극한기후지수 '서리일' 기준. 공식 한파일수(-12℃ 이하)는 11월 서울에서 거의 없음 |
| 안면도 | 오염원 영향을 받지 않은 배경대기농도, CO₂는 대기 중에 고르게 섞임 |
| 1999년 제외 | 결측 월(1·10·11월)이 CO₂가 높은 계절에 몰려 연평균이 과소추정됨 |
| CO₂ 연평균 | 계절 변동(광합성) 제거, 누적된 온실효과 반영 |
| ONI 사용 | 기상청 엘니뇨 정의와 같은 방식(ERSSTv5, Nino3.4, 3개월 이동평균). 우리나라 공공데이터 포털에는 수치 파일이 없음 |

## 5. 한계 (미리 적어둘 것)

- 26년이라 장기 추세를 보기엔 짧음
- 서울 한 지점 → 도시 열섬 효과가 섞여 있을 수 있음
- 북극진동, 시베리아 고기압 등 다른 자연 변동 요인은 넣지 않음
- 상관관계 ≠ 인과관계
- 2026년 SON 값은 11월이 끝나야 확정 → 예측에는 ASO 값을 대신 사용
